# Solutions to Dummit and Foote

An unofficial, community-driven LaTeX project for:

- worked solutions to selected exercises from *Abstract Algebra, 3rd Edition* by Dummit and Foote,
- supporting writeups and front-matter material,
- small coding experiments related to algebra topics.

This repository is an independent project and is not affiliated with the textbook authors or publisher.

## What Is In This Repository

- `dummit_foote_exercises.tex`: the main LaTeX source for the solutions document.
- `dummit_foote_exercises.pdf`: the generated PDF output already present in the repository root.
- `exercises/`: chapter and section solution files, organized by chapter folders such as `chapter0/`, `chapter1/`, and so on.
- `extra-text/`: front-matter content such as the preface and contributors.
- `coding-questions/`: Python scripts and text files used for algebraic computations and experiments.
- `.github`: PDF-syncing workflow to automatically upload to `blanketism.github.io`.
- `.githooks`: contains Python-based hook to automatically write commit messages.

## Contributing

Contributions are welcome.

1. Fork the repository.
2. Create a branch for your change.
3. Make edits with clear commit messages.
4. Ensure the relevant `.tex` files compile.
5. Open a pull request.

Suggested contribution style:

- keep notation consistent with surrounding material,
- keep chapter files focused and easy to review,
- prefer clear, self-contained explanations in the solution files.

## Notes On Scope and Attribution

This is an ongoing educational project intended to support learning. Please see the preface material in the compiled exercises document for additional context.
